# Python Simple Examples

A collection of simple Python examples for practicing basic programming concepts.

## Overview

This repository includes small Python scripts for learning and practicing:

* Variables and data types
* Functions
* Conditional statements
* Loops
* Lists and dictionaries
* Basic mathematical problems
* Prime number checking
* Simple command-line programs
* Basic API requests

## Files

| File                              | Description                                                                               |
| --------------------------------- | ----------------------------------------------------------------------------------------- |
| `calculator.py`                   | A simple command-line calculator for addition, subtraction, multiplication, and division. |
| `calculator_with_bug.py`          | A calculator script used for debugging practice.                                          |
| `BMI_homework1.py`                | A basic BMI calculator using functions and conditional statements.                        |
| `arrays.py`                       | Simple examples with Python lists.                                                        |
| `dictionary_sample.py`            | Basic dictionary usage.                                                                   |
| `finding_pin_using_dictionary.py` | A small example using dictionaries for value lookup.                                      |
| `function_test.py`                | Basic function practice.                                                                  |
| `if_test.py`                      | Conditional statement practice.                                                           |
| `for_test.py`                     | Loop practice.                                                                            |
| `primenumber.py`                  | Prime number checking and counting examples.                                              |
| `euler1.py`                       | Solution for finding the sum of multiples of 3 or 5 below 1000.                           |
| `euler2.py`                       | Another Project Euler-style practice problem.                                             |
| `api_01.py` to `api_04.py`        | Basic examples of working with API requests in Python.                                    |
| `1.py`                            | General Python practice file.                                                             |

## Requirements

Most files only need Python 3.

For the API examples, install `requests`:

```bash
pip install requests
```

## How to Run

Clone the repository:

```bash
git clone https://github.com/mhfakouri/python-simple-examples.git
cd python-simple-examples
```

Run any file with Python:

```bash
python calculator.py
```

Example:

```bash
python primenumber.py
```

For API examples:

```bash
python api_01.py
```

## Purpose

The purpose of this repository is to keep simple Python practice examples in one place and document basic programming exercises.
